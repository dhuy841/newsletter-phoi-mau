# Bài tập: Phối màu cho Newsletter

## Nội dung
- `newsletter_version1.html`: Fresh & Creative — xanh dương, xanh ngọc, nền sáng.
- `newsletter_version2.html`: Elegant & Warm — tím than, cam đất, kem.
- Cả hai dùng Bootstrap 5.3.3 và CSS Variables, có bố cục responsive.

## Cách chạy
1. Giải nén thư mục.
2. Mở một file HTML bằng trình duyệt; hoặc mở thư mục bằng VS Code và dùng Live Server.
3. Bootstrap được tải từ CDN nên cần kết nối Internet để hiển thị đúng.

## Lưu ý trước khi nộp
Bảng màu được đề xuất cho bài tập. Hãy mở Adobe Color (https://color.adobe.com/), chọn/xác nhận bảng màu và lưu lại ảnh chụp màn hình palette nếu giảng viên yêu cầu minh chứng đã sử dụng công cụ. Sau đó tải hai file HTML lên repository GitHub hoặc CodePen và nộp liên kết của bạn.
